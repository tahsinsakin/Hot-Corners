Sound familiar?

The tab you need is always in the middle.

Twenty-six tabs open, each squeezed to a sliver with a tiny icon. You squint, click the wrong one, press Ctrl+Tab, overshoot, and go back. A few seconds every time, dozens of times a day.

The fix isn't another toolbar button to aim at. Every page already has four spots that nothing else uses. Hot Corners turns them into shortcuts you can hit without looking, so your hands stay where they are and your attention stays on the work.

The tab overview

See every tab at once.

Every tab from every window, laid out as a grid with a preview of each page. You recognize tabs by how they look instead of hunting for titles.

Type to filter. Use the arrow keys and Enter. Close tabs right from the grid. Prefer the keyboard? Open it with Ctrl+Shift+Space.

Built to stay out of your way

It only fires when you mean it.

A shortcut that goes off by accident is worse than no shortcut. Every setting below exists for that reason.

Hold a key, if you like

Make any corner work only while Shift, Ctrl or Alt is held. Brush past it without the key and nothing happens.

Tune the trigger

Set how long the pointer rests before the action runs, and how big a corner is.

Quiet during movies

When a video or game goes full screen, the corners rest until you're done.

One key to switch it off

Ctrl+Shift+H turns everything off and back on. The toolbar icon goes grey while it's off.

Pause and forget

Pause for 15 minutes, an hour or until Chrome restarts. It comes back on by itself.

Leave some sites alone

Exclude any site with one click, so your design tool or game keeps its corners.

Get started

Install it in about a minute.

Hot Corners is coming to the Chrome Web Store. Until then, you can install it straight from GitHub:

  1. Download the code from GitHub (Code → Download ZIP) and unzip it.
  2. Open chrome://extensions and turn on Developer mode in the top-right corner.
  3. Click Load unpacked and choose the extension folder.
  4. Pin Hot Corners from Chrome's puzzle-piece menu. The top-left corner now opens your tab overview, and the bottom-right corner takes you back to your last tab.

Questions

Frequently asked questions

How do I add hot corners to Google Chrome?
Install the free Hot Corners extension, then open its settings and pick an action for each of the four corners. After that, resting the pointer in a corner of any web page runs that action, such as showing all your tabs or switching back to your last tab.
Is there a Chrome extension that shows all my open tabs at once?
Yes. Hot Corners has a tab overview that shows every tab from every Chrome window as a grid with a preview of each page. Open it from a corner or with Ctrl+Shift+Space, type to filter, and click or press Enter to switch.
How can I quickly switch back to the last tab I used in Chrome?
With Hot Corners, set a corner to "Last used tab". By default it's the bottom-right corner: rest the pointer there and Chrome jumps back to the tab you were on before, even if it's far away in the tab bar.
Does Hot Corners work on Windows, macOS and Linux?
It's built for the desktop version of Google Chrome (version 116 or later), which runs on Windows, macOS and Linux. Chrome doesn't allow extensions on its own pages, such as the New Tab page and Settings, so corners rest there.
Will it trigger by accident?
You control that. Each corner can require Shift, Ctrl or Alt to be held, you can set how long the pointer must rest and how big a corner is, corners rest during full-screen video, and Ctrl+Shift+H turns everything off in one keystroke.
Can I turn it off for certain websites?
Yes. Click the toolbar icon and switch it off for the current site, or add sites to the excluded list in settings. You can also pause it for 15 minutes, an hour, or until Chrome restarts.
Is Hot Corners free?
Yes. Hot Corners is free to use, with no account and no ads.
Does Hot Corners collect my data?
No. It collects nothing and sends nothing anywhere. Settings are stored in your Chrome profile, and tab previews stay in memory only until the browser session ends.
